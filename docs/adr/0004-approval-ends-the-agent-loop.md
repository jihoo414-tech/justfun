# 승인 카드가 나오면 에이전트 루프를 끝내고, 승인은 Spring이 직접 실행한다

비서가 승인이 필요한 도구를 부르면 Spring은 실행하지 않고 승인 카드를 DB에 저장한 뒤 "승인 대기 중"을 돌려준다. 루프는 그 자리에서 끝난다. 사용자가 승인하면 Claude를 거치지 않고 Spring이 카드에 고정된 값 그대로 실행하고, 그 결과를 대화방에 남긴 뒤 마무리 답변용 루프를 한 번 더 돌린다. 사용자가 언제 답할지 모르는데 루프를 열어 둔 채 기다리면 연결과 상태 관리가 어려워지고, 승인 후에 LLM이 값을 다시 정하게 하면 승인한 내용과 다르게 실행될 수 있기 때문이다.

## Consequences

- Python AI 서비스는 상태를 갖지 않는다. 매 루프마다 Spring이 대화 내용, 기억 메모, 그 상황에 허용된 도구 목록을 담아 보낸다.
- 카드는 대기, 승인됨, 거절됨, 만료됨 상태를 가진다. 승인 버튼을 여러 번 눌러도 한 번만 실행되도록 상태 전환으로 막는다.
