# 다른 모듈의 데이터는 ID로만 참조한다

Spring 백엔드의 한 모듈이 다른 모듈의 데이터를 가리킬 때는 숫자 ID 컬럼만 둔다. JPA 연관관계(`@ManyToOne` 등)로 다른 모듈의 엔티티를 직접 연결하지 않는다. 예를 들어 메시지는 승인 카드를 `approval_card_id`로만 가리킨다. 같은 모듈 안에서는 JPA 연관관계를 써도 된다. 나중에 모듈을 서비스로 떼어낼 때 DB 관계와 엔티티 그래프를 풀지 않아도 되고, 다른 모듈의 내부 클래스를 쓰지 못하게 하는 Spring Modulith 검증과도 맞아서 이렇게 정했다(ADR 0005).

## Consequences

- 다른 모듈의 데이터가 필요하면 그 모듈의 공개 API로 조회한다. 다른 모듈 테이블과 JOIN하거나 그 엔티티를 직접 읽지 않는다.
